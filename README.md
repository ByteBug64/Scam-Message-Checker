# Scam Message Checker

Paste any suspicious SMS, WhatsApp, or email message and get an instant 
check against common scam warning signs, urgency language, fake verification 
requests, prize scams, shortened links, and advance-fee patterns.

Everything runs in your browser. Nothing you type is sent anywhere.

## Limitation
Only catches scams matching known keyword patterns. New or cleverly 
worded scams may not be flagged.
